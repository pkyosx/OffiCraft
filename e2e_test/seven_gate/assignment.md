# 交辦內容（live actor 專用）— 逐字，不要改寫

`actors/live.sh` 在真 agent 開機**之前**，用 owner 身分把〈交辦原文〉那一段原樣送進聊天室。
那是這場關卡唯一給 agent 的輸入：一個**普通的工作請求**。

## 為什麼這段話不可以寫成「請你走這七步」

七步關卡問的問題是：**只讀開機說明的新 agent，會不會自己決定去開票、提計畫、報進度、
遇到要裁示的地方開卡問人、做完把票結掉。** 如果交辦裡直接列出這七件事，那量到的是
「它會不會照著清單做」——那件事不必花錢起一個真 agent 也知道答案是會。

所以下面這段話刻意只講**要什麼結果**，一個字都不提票、計畫、步驟、卡、結案。那五個字眼
該由開機說明教會它，教不會就是這張票要抓的病。

## 也刻意留了一個必須問人的岔路

交辦裡有一處**故意沒有講死**（放哪個位置）。那不是漏寫：⑥「開一張等我回覆卡」要成立，
現場就得真的存在一個「不問清楚就不該自己決定」的分岔。沒有這個分岔，一個表現完美的
agent 也沒有理由開卡，而那時候⑥的紅是我們自己造成的。

## 交辦原文

我要在這個隔離站上留一份「新人第一天該看什麼」的短清單，之後每個新進 agent 開機都會讀到它。
內容你自己判斷該寫什麼，三到五條、每條一句話就好。

放的位置我還沒決定，你先看過現場再跟我確認。

弄好之後跟我說一聲。
