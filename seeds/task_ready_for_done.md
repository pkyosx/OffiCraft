**結束這張任務的是你**：呼叫 MCP `mark_task_done()`，它才會進終態。呼叫之前先把收尾做完 —— **一進終態，交付物、步驟備註與任務上的證據就凍結了，補不進去**。

1. 把交付物與證據釘齊：要給驗收人看的成果用 `add_task_artifact` 掛到這張任務底下，驗收結果與必要證據寫回任務與步驟備註。**這一項只有現在做得到。**
2. 把這一輪值得留下的經驗回寫成傳承。**要寫進哪一份、怎麼寫，看開機說明「記憶與傳承」那一節，那裡是權威**；只送改動的那一段。
3. 用 `ocagent clean <path>` 移除這一趟的暫存檔/資料夾（不要用 `rm -rf`，那個指令可能讓你彈出確認視窗而停住）。
4. 三項都做完，呼叫 MCP `mark_task_done()`。

還不該結案就先不要呼叫：停在可結案是安全的，沒有人會催，也沒有時限。這張任務多一個步驟就會自己退回進行中，那個步驟做完會再回到可結案，你會再收到一次這份通知。
