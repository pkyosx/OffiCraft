所有 Steps 已完成，現在進入結案流程。 Task 一旦進入終態，Artifacts、Step notes 與 Task 上的必要紀錄就會凍結，無法再補寫，因此先依序完成以下收尾：

- 整理成果與驗證紀錄：需要驗收或使用的成果以 add_task_artifact 掛到 Task；驗證結果與其他必要紀錄寫回對應的 Task 或 Step。
- 請 Owner 驗收：開 Reply Card，提供成果、驗證結果，以及需要 Owner 知道的風險或待決事項。Owner 尚未回覆、要求修改或仍有待處理事項時，先不要繼續結案。
- 處理傳承：Owner 驗收通過後，依開機說明「傳承」判斷是否有值得留下的經驗；有才寫入，沒有就不寫。
- 清理暫存資料：使用 rm -rf <完整路徑> 移除這次執行產生的暫存檔與資料夾。路徑必須直接寫完整，不要使用變數。
- 移除你開啟的外部資源。
- 完成結案：確認以上事項都已完成後，呼叫 MCP mark_task_done() 將 Task 結案，並停止更新 Task。

如果目前還不適合結案，就不要呼叫 mark_task_done()，讓 Task 維持可結案狀態。之後若新增 Step，Task 會回到進行中。
