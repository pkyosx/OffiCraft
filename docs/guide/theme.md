# 主題（外觀與用語）

主題決定控制台**長什麼樣、用什麼字**：一整套顏色，加上一份可選的用語覆蓋。內建主題是**辦公室（深色）**（預設）與**辦公室（淺色）**；除此之外，你可以**自己新增主題**、調色、改用語，也能把主題**匯出成一個檔案**分享、或**匯入**別人做好的主題。

> 主題不會動到版面位置，只換顏色與用語；也**不會蓋過語言設定**——主題和語言各自獨立，你可以「辦公室（淺色）+ English」或「自訂配色 + 中文」任意搭。

---

## 兩個地方，分工不同

| 在哪 | 做什麼 |
| --- | --- |
| **頭像下拉 › 偏好設定** | **選**要用哪個主題（內建主題，或你已建立／匯入的自訂主題）＋語言＋版面＋是否顯示應景主題。只是切換，不在這裡編輯；密碼與兩步驟驗證不在這一頁。 |
| **⚙️ 齒輪 › 設定 › 主題** | **管理**主題：新增、編輯顏色與用語、匯入、匯出、刪除。 |

一句話：**偏好設定選主題，設定頁管理主題。**

---

## 深色與淺色

**辦公室（深色）**與**辦公室（淺色）**是同一套介面的兩種配色，只換顏色，不換圖片與用語。選了淺色，整個控制台（辦公室、請示、任務、傳承、監控、使用說明、設定）都換成淺色；**登入頁**沿用這台瀏覽器上次選的主題，打開時不會先閃一下深色。

- 按「登出」會把這台瀏覽器的主題重設回預設的辦公室（深色），所以登出後的登入頁是深色，下一個在這台電腦登入的人不會看到前一個人的選擇；只是登入過期、沒有按登出時，登入頁維持原本的主題。
- 新建立的站台預設是辦公室（深色）。
- 主題不會跟著作業系統的深淺色設定自動切換，要換就自己在偏好設定選。

## 應景主題

節日期間（例如萬聖節），控制台會自動換上一套跟著版本出貨的**應景主題**：顏色、用語、頭像、標誌、導覽圖示與背景整套換掉，時間到了自己換回你選的主題，不用重新整理。

- 起訖時間跟著版本出貨、不能調整，以**你這台電腦的當地時間**計算。
- 它不會改掉你在偏好設定選的主題，也不會出現在主題清單裡，不能選來長期使用。
- 不想看到它：**頭像下拉 › 偏好設定 › 顯示應景主題**切到「關」，這個選擇會跟著你的帳號到每台裝置。

## 新增一個自訂主題

到 **設定 › 主題**：

1. **新增** → 點一下就以辦公室（深色）為底建立一份可編輯副本、直接進編輯器（會先帶一個預設名字，你在編輯器裡改成想要的，例如「深海」）。想從淺色出發，就在內建的「辦公室（淺色）」那列按**匯出**，再把那個檔案**匯入**、改名來改。
2. **改顏色** — 顏色照用途分組（主色、背景、文字、狀態…），每一項給的是**看得懂的名稱**（例如「強調色」而不是內部代號）配一個**視覺取色器**，點開挑色即可。
3. **改字型（可選）** — 內文與標題各可從一份安全字型清單挑一款（含標楷體等中文字型）；不挑就沿用預設字型。
4. **改頭像（可選）** — 可分別為正職／外包各上傳一張頭像圖；套用這個主題時，成員卡與聊天就會顯示它。
5. **改用語（可選）** — 一份可搜尋的清單，每一列是「**英文原詞 + 目前顯示的文字**」，你對著要改的那條填新字。沒改的維持原本的語言。
6. 存檔後回偏好設定選它套用，整套外觀（顏色＋字型＋頭像＋你改過的用語）立刻上身。

> 顏色只能從**開放的具名色槽**裡挑（大約 40 個顏色角色），字型只能從**安全字型清單**挑，用語也只能覆蓋**既有的介面字詞**——你不能塞入任意 CSS、字型檔或程式碼。這是刻意的安全設計，避免破版與注入風險。

## 匯入與匯出（分享主題）

- **匯出** — 在設定 › 主題把目前主題輸出成一個 `.json` 主題包檔。自訂主題匯出的是**完整主題包**——顏色 + 用語 + 字型 + 頭像，一項都不漏；內建主題本身沒有這些覆蓋，每一列匯出的就是那一套自己的整組顏色，不管你現在套用的是哪一套。
- **匯入** — 選一個 `.json` 檔（或貼上內容），系統驗證通過後就加進你的主題清單，跟自己建的一視同仁。驗證會擋掉非法色值、未知色槽、任意 CSS、或超長內容——匯入來路不明的主題包是安全的。

一個主題包就是一份純資料（顏色 + 用語 + 字型 + 頭像），拿給別人匯入就能得到一模一樣的外觀。

## 「修仙」主題

OffiCraft 早期把「修仙」做成內建主題（把介面用語整套換成修仙講法）。現在它不再是內建——**內建只留辦公室（深色與淺色）**。修仙改成一份**可匯入的主題包**：想試就用上面的「匯入」把修仙主題包匯進來，效果一樣，但它跟任何自訂主題一樣可選、可改、可刪，不再是寫死在程式裡的特例。
