# 主題（外觀與用語）

讀完這頁，你能切換深色與淺色主題、關掉應景主題、自己做一套主題（顏色、用語、字型、頭像、Logo、導覽圖示、背景），以及匯入、匯出主題分享給別人。

主題只換外觀與用語，不改版面位置，也不改語言設定：主題和語言各自獨立，例如可以用「辦公室（淺色）」配 English。

## 選用主題與管理主題

| 在哪裡 | 做什麼 |
| --- | --- |
| 頭像選單 › 偏好設定 › 主題 | 選要用哪個主題：內建主題，或你已建立、匯入的自訂主題 |
| 設定 › 主題 | 新增、匯入、匯出、編輯、刪除主題 |

同一個偏好設定裡還有語言、版面（窄版／寬版）與「顯示應景主題」。

## 內建主題：深色與淺色

內建主題有兩套：**辦公室（深色）** 與 **辦公室（淺色）**。兩者只差在顏色，圖示與用語相同。選了之後，整個控制台（包含每個分頁與設定）都換成那套顏色。

- 新建立的工作室預設是辦公室（深色）。
- 登入頁沿用這台瀏覽器上次使用的主題。
- 按「登出」會把這台瀏覽器的主題重設回辦公室（深色），下一個在這台電腦登入的人不會看到前一個人的選擇；登入過期而不是按登出時，登入頁維持原本的主題。
- 主題不會跟著作業系統的深淺色設定自動切換。

## 應景主題

在特定節日期間（例如國慶日、萬聖節），控制台會自動換上隨版本附帶的應景主題，顏色、用語、頭像、Logo、導覽圖示與背景整套換掉。時段結束後自動換回你選的主題，不必重新整理。

- 每個應景主題的起訖時間隨版本附帶，不能調整，以你這台電腦的當地時間計算。兩個時段重疊時，同一時間只顯示一個。
- 應景主題不會改掉你在偏好設定選的主題，也不在主題清單裡，不能選來長期使用。
- 應景主題期間，畫面上的用語會跟這份說明不同。
- 不想看到應景主題：頭像選單 › 偏好設定 › 顯示應景主題，切到「關」。這個選擇跟著你的帳號，在每台裝置都有效。

## 新增自訂主題

到「設定 › 主題」按「新增」。系統以辦公室（深色）為底建立一份副本，直接打開編輯器，名稱先帶「新主題」，可以在「名稱」欄改掉。想從淺色開始，就在「辦公室（淺色）」那一列按「匯出」，再把匯出的檔案匯入、改名後編輯。

自訂主題最多 100 套。

編輯器有以下區塊，除了顏色以外都可以留空，留空就沿用內建的設計：

- **顏色** — 七十多個具名顏色，依用途分組：主色、背景與表面、文字、狀態、狀態點、圖示、相依、裝飾、其他。每一項用看得懂的名稱標示，點開用取色器挑色，也可以調不透明度。
- **用詞** — 一份可以搜尋的介面用語清單，在要改的那一條填「替代字」即可覆蓋；留空則維持原文。
- **字型** — 「內文字型」與「標題字型」各從一份內建的安全字型清單挑選（含標楷體、黑體、宋體、圓體等中文字型）；選「預設(主題字型)」就沿用原字型。
- **頭像** — 正職頭像、外包頭像、CEO 頭像、助理頭像，各可上傳一張（PNG、JPEG、WEBP，上限 64 KB）。
- **工作室 Logo** — 頂列左上角的 Logo（PNG、JPEG、WEBP，上限 64 KB）。
- **導覽圖示** — 辦公室、請示、任務、傳承、監控、使用說明六個分頁的圖示，各可上傳一張（PNG、JPEG、WEBP，上限 64 KB）。密鑰分頁的圖示不能換。
- **外框背景** — 疊在底色上的一張圖（PNG、JPEG、WEBP，上限 512 KB），鋪法有三種：
  - **平鋪** — 重複鋪滿內容欄兩側的外框。
  - **貼邊** — 左右各貼一張，不做鏡像；要左右對稱就直接畫成對稱的圖。
  - **滿版** — 一張圖填滿整個視窗。只有在這個主題把頂列、頁籤列、內容區的顏色設成半透明（`#RRGGBBAA` 或 `rgba`）時才看得到，圖與文字的對比要自己顧。
  - 平鋪與貼邊只畫在內容欄兩側，所以在手機、窄視窗與寬版版面上看不到。

存檔後回到頭像選單 › 偏好設定選它，就會套用。

顏色只能填具體的色值，字型只能從安全字型清單挑，用詞只能覆蓋既有的介面用語，不能放入任意 CSS、字型檔或程式碼。

## 匯出與匯入

**匯出**：在「設定 › 主題」某一列按「匯出」，得到一個 `.json` 主題檔。自訂主題匯出的是完整內容：顏色、用詞、字型、頭像、Logo、導覽圖示、外框背景都在檔案裡。內建主題匯出的是那一套的整組顏色。

**匯入**：按「匯入」，有三種方式：

- 在「在此貼上主題 JSON…」貼上主題檔的內容。
- 「選擇 .json 檔」。
- 在「…或貼一條連結匯入」貼上主題檔的網址，按「抓取並匯入」。帶背景圖的主題檔通常太大，無法直接貼進聊天，用連結傳遞比較方便。拿到這條連結的人都能看到這套主題（包含裡面的私人圖片），連結不會過期，也無法單獨收回。

匯入前會先檢查內容，不合法的色值、任意 CSS、過大的內容都會被擋下，所以匯入別人給的主題檔是安全的。另外：

- 主題檔裡有不認得的用詞代碼時，仍然會匯入，但會列出被略過的代碼。
- 已經有同一套自訂主題時，會提示「已經有同一套自訂主題」。
- 主題的 id 和內建應景主題相同時無法匯入，要先改掉主題檔裡的 id。
