# 主題（外觀與用語）

讀完這頁，你能選擇控制台的外觀、讓主題依時段自動切換、關掉應景主題、自己做一套主題，以及匯入、匯出主題分享給別人。

主題只換外觀與用語，不改版面位置，也不改語言。主題和語言各自獨立，例如可以用「辦公室・淺色（無背景）」配 English。

## 選擇外觀

主題設定有兩個入口，內容一樣：頭像選單 › 偏好設定的「主題」，以及按頂列的齒輪進入 **設定 › 主題**。

內建主題有五套：「辦公室・晨光」、「辦公室・暮色」、「辦公室・夜燈」三套帶辦公室背景，「辦公室・深色（無背景）」、「辦公室・淺色（無背景）」兩套只有顏色。主題不會跟著電腦的深淺色設定自動切換。

按「恢復預設」可以改回新工作室的預設外觀，自訂主題不會被刪除。

## 依時段自動換主題

新建立的工作室預設依時段切換主題：06:00 換成辦公室・晨光、16:00 換成辦公室・暮色、18:30 換成辦公室・夜燈。

時段和每個時段用的主題都可以改，也可以把「依時段切換」關掉，固定用一套主題。時間以你這台裝置的當地時間計算；設定跟著你的帳號，在每台裝置都有效。

## 關掉應景主題

節日期間（例如國慶日、萬聖節），控制台會自動換上應景主題，顏色、用語、頭像、Logo、導覽圖示與背景整套換掉。時段結束後，控制台會自動換回原本的主題，不必重新整理。應景主題期間，畫面上的用語會跟使用說明不同。

不想看到應景主題，在主題設定把「顯示應景主題」切到「關」。

## 自己做一套主題

1. 按頂列的齒輪，進入 **設定 › 主題**，按「新增」。
2. 編輯器打開後，在「名稱」改一個你認得的名字。
3. 調整想改的部分：顏色、用詞、字型、頭像、工作室 Logo、導覽圖示、外框背景。除了顏色以外都可以留空，留空就沿用內建的設計。
4. 存檔後，在主題設定選這套主題，或把這套主題排進時段，就會套用。

新增的主題以辦公室・深色（無背景）為底。想從別的內建主題開始，先在那一套主題的那一列按「匯出」，再把匯出的檔案匯入、改名後編輯。

想知道更多細節，例如每個區塊能改什麼、圖片的大小上限、外框背景的鋪法，見 [設定與參數](settings.md) 的「主題」。

## 匯出與匯入

**匯出**：在 **設定 › 主題** 某一列按「匯出」，會得到一個 `.json` 主題檔。

**匯入**：按「匯入」，可以貼上主題檔的內容、選擇 `.json` 檔，或貼上主題檔的連結，三種方式擇一。

匯入前，系統會先檢查內容，不合法的色值、任意的程式碼、過大的內容都會被擋下，所以匯入別人給的主題檔是安全的。

**用連結分享主題時要注意**：拿到連結的人都能看到這套主題，包括裡面的私人圖片；連結不會過期，也無法單獨收回。

想知道更多細節，例如匯出的檔案包含哪些內容、匯入時出現的提示是什麼意思，見 [設定與參數](settings.md) 的「主題」。
