# 增加成員與發外包

讀完這頁，你能分辨正職與外包、新增一位正職成員、設定外包怎麼被雇用，並看懂成員現在的狀態、決定它在哪台機器上用哪個模型執行。

## 正職與外包

辦公室分頁左側的「辦公室成員」有兩個頁籤：**正職** 和 **外包**。頁籤下的小字顯示人數，外包頁籤另外顯示上限，例如「3 人 · 上限 5」。

| | 正職 | 外包 |
| --- | --- | --- |
| 身分 | 有名字、有角色，例如出廠就有的特助 Mira | 沒有角色，以代號稱呼，例如「外包 · O-7」 |
| 存在多久 | 常駐，你關掉瀏覽器它仍在 | 綁一張任務，任務結案後釋出 |
| 怎麼產生 | 你新增一個角色 | 任務手冊或轉派指定交給外包時，由 server 自動雇用 |
| 跨任務的記憶 | 角色定義、判準與它自己的成員傳承 | 只有它自己寫的傳承，以及任務手冊上的任務傳承 |
| 怎麼工作 | 主要負責協調，粗重的工作交給子代理或發外包 | 自己動手做完整件工作 |

出廠時工作室裡只有你（owner）和特助 Mira。

## 新增一位正職

一位正職對應一個角色。新增正職就是新增一個角色定義：

1. 在辦公室分頁切到「正職」頁籤，按左側最下方的「招攬新成員」。畫面會帶你到 **設定 › 角色誌** 的新增畫面（也可以自己從齒輪 › 設定 › 角色誌 按「新增角色定義」）。
2. 填「角色名」，按「建立」。
3. 打開新角色，寫好角色定義：該角色負責什麼、哪些事不能做。寫法見 [讓成員記住你教過的事](lore.md)。
4. 新成員建立時是離線的，不會自動上線。到辦公室點它的頭像打開成員詳情，按「喚醒」。

角色可以在角色誌按「重新命名角色」改名。成員本身的顯示名稱在成員詳情按「改名」修改。

### 刪除角色

在 **設定 › 角色誌** 對角色按「刪除」並確認：

- 該角色的正職成員會標記為已離開，聊天紀錄保留為唯讀歷史。
- 角色定義與判準會永久刪除，無法復原，版本紀錄也一起刪除。
- 有成員在線上時無法刪除，畫面會顯示「有成員在線上，無法刪除」。先停止該成員再刪。
- 內建的特助角色不能刪除。

新增、改名與刪除角色，你和特助都能做。

## 喚醒與啟動設定

在成員詳情按「喚醒」，會先打開一份啟動設定，確認後才啟動。四個欄位一開始都是該成員目前的設定，只改需要改的即可：

- **AI 執行環境**：Claude Code 或 Codex。
- **模型**：Claude Code 有 fable、opus、sonnet、haiku 快選；Codex 有 astra、sol、terra、luna 四個型號系列快選。也可以在輸入框直接打完整的型號名稱，會照原樣使用；留空則使用該機器的預設模型。
- **EFFORT · 思考強度**：低／中／高／極高／最高。
- **機器**：要在哪台機器上執行。

Codex 選型號系列時，成員每次開機會用該機器的 Codex 認得的該系列最新型號，所以換機器或 Codex 升級後，實際型號可能不同。成員詳情上方的「模型」顯示實際使用的完整型號。該機器的 Codex 沒有該系列時，成員不會啟動，「最近操作」會寫出那台 Codex 的版本和可用型號。

同一個設定在不同畫面的名稱不同：成員詳情與啟動設定裡叫「思考強度」，任務手冊的負責成員設定叫「投入程度」，外包詳情與任務卡上叫「投入度」（例如「高投入」）。

### 還沒選過執行環境的新成員

新增的正職和出廠的 Mira 一開始沒有選定執行環境。啟動設定裡顯示的「Claude Code」只是預設顯示值，原封不動送出不會把它存下來。真正的執行環境在它第一次被派到機器上時決定：該機器裝好了 Claude Code 就用 Claude Code，只裝了 Codex 就用 Codex，決定後就固定在該成員身上。

要指定執行環境，就在啟動設定裡明確選一次。只裝了 Codex 的機器上有成員起不來時，把它的執行環境改成 Codex，步驟見 [常見問題與排解](troubleshooting.md)。

### 成員在執行中時改設定

成員喚醒中、線上或停止中時，「喚醒」的位置換成「更改」，打開的是同一份啟動設定。按下後會發生什麼，設定框下方會依當時狀態說明：

- **線上**：它會先把手上的事收尾，再用新設定重新開起來。收尾期間成員詳情顯示「正在收尾以套用你的改動」。
- **停止中**：存下新設定，它停下後會用新設定重新開起來。
- **喚醒中**：換了機器會移到新機器、用新設定重新開起來；只換型號、執行環境或思考強度，下次開起來才生效。

換機器時，成員詳情的「機器」會繼續顯示目前的機器，旁邊加上「→ 要換到 機器名稱」，換完後標示消失。

## 上線、下線與停止

成員頭像角落的圓點表示它是否在線上：

| 狀態 | 意思 |
| --- | --- |
| 離線 | 沒有在執行 |
| 喚醒中 | 已送出喚醒，正在啟動 |
| 線上 | 已連上 server，可以對話 |
| 停止中 | 正在收尾 |
| 已停止 | 已停下 |

滑鼠移到圓點上（手機上點一下）會顯示狀態名稱。「線上」的意思是成員目前與 server 保持連線；連線中斷就算離線。

成員離線時仍可以在聊天框留言。聊天室會顯示「目前離線中 — 訊息會排隊，或立即喚醒上線」，訊息會在它上線後讀到，也可以直接按旁邊的「喚醒」。

成員詳情右上角的操作：

- **喚醒**：離線或已停止時出現。按下會先打開啟動設定，確認執行環境、模型、思考強度與機器後才開始。
- **更改**：喚醒中、線上或停止中時出現。
- **停止 → 加速停止 → 強制停止**：同一顆按鈕依階段改變。
  - 「停止」請成員正常收尾後停下，沒有時限。
  - 成員進入收尾後，按鈕變成「加速停止」。按下後給它一個明確的期限並通知它，期限秒數在 設定 › 參數調整 的「加速停止秒數」。成員記憶用量到達「第一次通知」的比例、系統自動開始的收尾，也會出現「加速停止」；到了「最後通牒」，收尾已經有期限，按鈕會直接變成「強制停止」。
  - 收尾有了期限後，按鈕變成「強制停止」。按下會先確認：「跳過正常收尾，進行中未存的工作會遺失」。這是最後手段。
  - 按鈕剛換階段時有短暫時間不能按，避免連按兩下直接跳到下一階。
- **重新聚焦**：只有線上時能按。成員會整理記憶、收尾目前這一手，再開新的一手接著做，手上的任務不受影響。成員記憶快滿時系統也會自動做同樣的事，門檻在 設定 › 參數調整。

操作失敗時，按鈕下方會顯示「操作失敗，請稍後重試」。每次喚醒或停止的結果記在成員詳情的「最近操作」，啟動失敗的原因（例如「機器名稱 未登入 Claude」）也寫在這裡。

## 運作狀態圖示與警示

成員名字前面的圖示表示它現在在做什麼，會出現在成員名單、聊天室標題和成員詳情：

| 圖示 | 狀態 |
| --- | --- |
| 星星 | 工作中 |
| 沙漏 | 等待中，例如在等背景指令或排程 |
| 咖啡杯 | 閒置 |
| 問號類的未知圖示 | 狀態未知：成員在線上但還沒回報狀態 |
| 月亮 | 離線或已停止 |

成員在線上時，點圖示會打開「運行狀況」，「目前狀態」會寫出例如「主代理工作中，另有 2 個子代理工作中，正在等 1 個背景檢查或排程」，並列出主代理、各子代理已工作多久，以及正在等的背景指令與排程。

名字旁出現驚嘆號時，表示該成員目前無法正常呼叫模型。點驚嘆號會顯示原因：

- **未登入 Claude**／**未登入 Codex**：該機器的執行環境沒有登入。
- **登入失效**：登入過期，需要重新登入。
- **已達用量上限**：帳號用量用完；知道重置時間時會一併顯示。
- **伺服器異常**、**模型呼叫失敗**：模型服務端的錯誤。

登入問題的處理方式在原因提示裡：到「監控」頁的機器資訊，在 Claude 或 Codex 欄按版本號 →「登入」。

使用主題時，圖示樣式可能不同，狀態的意思不變。

## 頭像

你可以在成員詳情或外包詳情按「更換頭像」上傳個人頭像，或按「移除頭像」移除。支援 PNG、JPEG、WEBP，檔案不可超過 64 KiB。只有你能修改，成員不能改自己或別人的頭像。

頭像會出現在名單、聊天、任務、請示卡、詳情與監控頁。沒有個人頭像或圖片載入失敗時，依序改用主題設定的頭像、內建圖示。頭像綁定成員本身，成員改名不影響。

## 發外包

外包由 server 依任務手冊的設定自動雇用，你不必一個一個開。

### 在任務手冊指定外包

1. 到 **設定 › 任務手冊**，打開一本手冊。
2. 在「負責成員」選「外包」。
3. 設定 AI 執行環境、模型、投入程度。
4. 選「機器」。「機器」一定要選：該類任務的外包只會在選定的機器上喚醒。沒選機器，或該機器離線、沒有裝所選的執行環境時，一律不喚醒，也不會改派到其他機器，原因會顯示在該外包上。
5. 設定「雇用數量」：該類任務同時最多幾個外包在做。按「無限」（顯示為 ∞）表示該類任務不設上限，但仍受全域的外包上限限制。

手冊的負責成員只有你和特助能設定，其他成員改不了。手冊的其他欄位怎麼寫，見 [讓 AI 照 SOP 做重複的事](sop.md)。

### 把單一張任務轉給外包

任務卡的狀態選單有「轉派…」，選「轉外包」並選擇要運行的機器，可以把一張已經在進行的任務交給一個新的外包。轉派細節見 [追蹤任務進度](tasks.md)。

### 全域外包上限

在辦公室分頁切到「外包」頁籤，按左側最下方的「招攬新成員」，打開「外包上限設定」：

- **最多雇用 N**：整間工作室同時最多 N 個外包在執行，滿了就排隊，有空位自動接下一個。
- **無限**：不設上限。
- **0**：暫停指派。現有的外包繼續做完，不再雇用新的；頁籤上會顯示「已暫停指派」。

按「完成」儲存。

### 外包名單上看得到什麼

外包頁籤的每一列依任務建立時間由新到舊排列，顯示：

- 頭像與在線圓點、運作狀態圖示、代號。
- 驚嘆號警示（有的話）、任務編號、任務類型。點任務編號會跳到那張任務。
- 任務標題；沒有進行中的任務時顯示「無當前任務」。
- 未讀訊息數。

點一列打開和這位外包的聊天，點頭像打開外包詳情。外包詳情有和成員詳情相同的喚醒、更改、停止、重新聚焦與頭像操作，也能看到機器、記憶用量、估計$、最近操作和終端 · TMUX 指令。

任務結案後，該外包會釋出並從名單消失。它的聊天紀錄仍保留，從舊訊息或舊連結打開時會顯示「外包 · 已釋出」與「此外包成員已結案釋出,這裡是唯讀的歷史紀錄」，不再有喚醒或停止等操作。

## 什麼時候該外包

適合交給外包的工作：

- **可以獨立切出去、做完就結案的一整件事**，例如「審查這一個 PR」「把這份資料整理成報告」。
- **想同時推進很多件同類的工作**：一次交出去多張，由雇用數量和全域外包上限控制同時有幾個在做，滿了自動排隊。
- **不需要累積角色記憶的工作**：外包留下的經驗寫成任務傳承，掛在該類任務的手冊上，下一個做同類任務的成員讀得到。

外包會在選定的機器上用你的 Claude 或 Codex 帳號執行，用量算在你的帳號上。全域外包上限是控制同時用量的主要方式。

## 什麼時候該加一個常駐成員

正職有固定身分，角色定義、判準和它自己的成員傳承都會跟著它，換手後仍然存在。新增一個角色需要你寫好角色定義，所以值得在下列情況才新增：

- **一個領域或一個 repo 需要長期累積經驗**：它會逐漸熟悉這塊的做法、你的偏好和常見問題，換手後不必重學。
- **某類協調工作反覆出現，需要固定的窗口**：例如特助 Mira 負責分派與追進度，或一個專責發版的角色。
- **希望判斷原則隨時間愈來愈準的工作**：判準與成員傳承會一手接一手保留下來。

下列情況不必新增正職，交給外包即可：

- 一次性、做完就結案的工作。
- 需要大量並行的同類工作。
- 經驗寫成任務傳承就足夠、不需要一個角色承載的工作。

判斷方式：需要同一個角色長期接手、經驗逐次累積，就新增正職；只是要把一件事做完，就發外包。正職本身也會把粗重的工作交給子代理或發外包，新增正職不代表所有事都由它親自做。
