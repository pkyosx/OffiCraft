# 增加成員與發外包

讀完這頁，你能分辨正職與外包、新增一位正職成員、喚醒與停止成員、看懂成員現在的狀態，並判斷一件工作該發外包還是該加一位常駐成員。

## 正職與外包

辦公室分頁左側的「辦公室成員」有兩個頁籤：「正職」和「外包」。

| | 正職 | 外包 |
| --- | --- | --- |
| 身分 | 有名字、有角色，例如出廠就有的特助 Mira | 沒有角色，以代號稱呼，例如「外包 · O-7」 |
| 存在多久 | 常駐，你關掉瀏覽器，正職成員仍然在工作 | 只為一張任務存在，任務結案後離開 |
| 怎麼產生 | 你新增一個角色 | 任務手冊或轉派指定交給外包，或正職成員把工作發包出去時，系統自動找一位外包 |
| 記得什麼 | 使用者自訂、角色定義、判準、「所有人」的傳承與自己的成員傳承 | 使用者自訂、「所有人」的傳承，以及任務手冊上的任務傳承 |
| 怎麼工作 | 主要負責協調，粗重的工作交給子代理（成員自己開出來分擔工作的 AI 助手）或發外包 | 自己動手做完整件工作 |

出廠時工作室裡只有你和特助 Mira。

## 新增一位正職

一位正職對應一個角色，新增正職就是新增一個角色：

1. 在辦公室分頁切到「正職」頁籤，按左側最下方的「招攬新成員」。畫面會帶你到 **設定 › 角色誌** 的新增畫面。
2. 填「角色名」，按「建立」。
3. 打開新角色，寫好角色定義：這個角色負責什麼、哪些事不能做。寫法見 [讓成員記住你教過的事（傳承）](lore.md)。
4. 新成員建立時是離線的。到辦公室點新成員的頭像，打開成員詳情，按「喚醒」。

角色的名稱在角色誌按「重新命名角色」修改；成員的顯示名稱在成員詳情按「改名」修改。

**刪除角色**：在 **設定 › 角色誌** 對角色按「刪除」並確認。該角色的正職成員會標記為已離開，聊天紀錄保留為唯讀；**角色定義與判準會永久刪除，無法復原**。有成員在線上時無法刪除，要先停止成員。

新增、改名與刪除角色，你和特助都能做。想知道更多細節，見 [設定與參數](settings.md) 的「角色誌」。

## 喚醒成員

成員離線時，到「辦公室」點成員的頭像，按「喚醒」。畫面會帶出這位成員上次用的設定，直接按確認，成員就會上線開始工作。

大部分時候不需要改設定。想調整時，可以改這四項：

- **AI 執行環境**：用 Claude Code 還是 Codex。沒選過時，系統會依機器裝了哪一個自動決定，見 [架構與運作原理](architecture.md) 的「成員用 Claude Code 還是 Codex」。
- **模型**：較強的模型做得比較好，也比較花錢。
- **思考強度**：越高想得越久，也越花錢。日常工作選「中」通常就夠。
- **機器**：有好幾台機器時，選要在哪一台上執行。

成員正在工作時，「喚醒」會變成「更改」。改了設定之後，成員會先把手上的事情收尾，再用新的設定繼續，不會做到一半被打斷。

想知道更多細節，例如 Codex 的型號怎麼挑、同一個設定在不同畫面叫什麼名字，見 [介面說明](interface.md) 的「辦公室」。

## 停止成員與重新聚焦

在成員詳情右上角按「停止」，成員會先把手上的事收尾，再停下來。正常收尾沒有時限。

想讓成員快一點停下來，再按同一顆按鈕：按鈕會依序變成「加速停止」（給收尾一個期限）和「強制停止」（立刻結束）。**強制停止會跳過收尾，進行中還沒存的工作會遺失**，只在不得已時使用。

成員在線上時，可以按「重新聚焦」：成員會整理記憶、重新開始，手上的任務不受影響。成員記憶快滿時，系統也會自動這樣做。

喚醒或停止沒有成功時，原因寫在成員詳情的「最近操作」。處理方式見 [常見問題與排解](troubleshooting.md)。

## 看懂成員的狀態

成員頭像右下角的**圓點**表示成員有沒有上線。把滑鼠移到圓點上（手機上點一下）會顯示狀態名稱：

| 狀態 | 意思 |
| --- | --- |
| 離線 | 沒有在執行 |
| 喚醒中 | 正在啟動 |
| 線上 | 可以對話 |
| 停止中 | 正在收尾 |
| 已停止 | 已停下 |

成員名字前面的**圖示**表示成員現在在做什麼：

| 圖示 | 狀態 |
| --- | --- |
| 星星 | 工作中 |
| 沙漏 | 等待中，例如在等背景執行的指令或排程 |
| 咖啡杯 | 閒置 |
| 圓圈問號 | 狀態未知：成員在線上，但還沒回報狀態 |
| 月亮 | 離線或已停止 |

名字旁出現**驚嘆號**時，表示這位成員現在沒辦法正常使用 AI 模型。點驚嘆號會顯示原因：

- **未登入 Claude**／**未登入 Codex**、**登入失效**：到「監控」分頁的機器資訊，在那台機器的 Claude 或 Codex 欄按版本號，選「登入」。
- **已達用量上限**：帳號的用量用完了，等重置時間到就會恢復。
- **伺服器異常**、**模型呼叫失敗**：AI 模型服務那一邊出錯。

成員離線時，仍然可以在聊天框留言，成員上線後就會讀到。

想知道更多細節，例如「運行狀況」裡寫了什麼、每個狀態背後怎麼判定，見 [介面說明](interface.md) 的「辦公室」和 [架構與運作原理](architecture.md) 的「成員的狀態怎麼判定」。

## 頭像

在成員詳情或外包詳情按「更換頭像」上傳圖片（PNG、JPEG、WEBP，不超過 64 KiB），按「移除頭像」移除。只有你能修改頭像。

## 發外包

外包不用你一個一個找。下列三種情況，系統會自動找外包來做：

- 任務手冊的「負責成員」選了外包。
- 你把一張任務轉派給外包。
- 正職成員把一件沒有手冊的工作直接發包給外包。

### 在任務手冊指定外包

1. 到 **設定 › 任務手冊**，打開一本手冊。
2. 在「負責成員」選「外包」。
3. 設定 AI 執行環境、模型和投入程度。
4. 選「機器」。
5. 設定「雇用數量」：這一類任務同時最多幾位外包在做。按「無限」表示這一類任務不設上限，但仍受整間工作室的外包上限限制。

**「機器」一定要選。** 外包只會在選定的機器上工作。沒選機器，或選的機器離線、沒有裝所選的 AI 執行環境時，外包一律不會開始，也不會改到其他機器，原因會顯示在該外包上。

手冊的負責成員只有你和特助能設定。手冊的其他欄位怎麼寫，見 [讓 AI 照 SOP 做重複的事（任務手冊）](sop.md)。

### 把單一張任務轉給外包

按任務卡「負責人」旁的交換圖示（滑鼠移上去顯示「轉派…」），選「轉外包」並選擇機器，就能把一張已經在進行的任務交給一位新的外包。轉派的細節見 [追蹤任務進度](tasks.md)。

### 整間工作室的外包上限

在辦公室分頁切到「外包」頁籤，按左側最下方的「招攬新成員」，打開「外包上限設定」：

- **最多雇用 N**：整間工作室同時最多 N 位外包在工作。滿了就排隊，有空位時自動接下一張。
- **無限**：不設上限。
- **0**：暫停指派。正在做的外包會繼續做完，但不再找新的外包；頁籤上會顯示「已暫停指派」。

按「完成」儲存。

外包用的也是你的 Claude 或 Codex 帳號，用量算在你的帳號上。**外包上限是控制同時用量的主要方式。**

任務結案後，外包會離開名單。外包的聊天紀錄仍然保留，可以唯讀查看。外包名單上每一列顯示什麼，見 [介面說明](interface.md) 的「辦公室」。

## 什麼時候該發外包

適合交給外包的工作：

- **可以獨立切出去、做完就結案的一整件事**，例如「審查這一個 PR」「把這份資料整理成報告」。
- **想同時推進很多件同類的工作**：一次交出去多張，由雇用數量和外包上限控制同時有幾位在做，滿了自動排隊。
- **不需要累積角色記憶的工作**：外包留下的經驗寫成任務傳承，掛在該類任務的手冊上，下一個做同類任務的成員讀得到。

## 什麼時候該加一位常駐成員

正職有固定身分，角色定義、判準和自己的成員傳承都會一直保留。新增一個角色需要你寫好角色定義，所以在下列情況才值得新增：

- **一個領域或一個 repo 需要長期累積經驗**：正職成員會逐漸熟悉這塊的做法、你的偏好和常見問題。
- **某類協調工作反覆出現，需要固定的窗口**：例如特助 Mira 負責分派與追進度，或一個專責發版的角色。
- **希望判斷原則隨時間愈來愈準的工作**：判準與成員傳承會一直保留下來。

下列情況不必新增正職，交給外包即可：

- 一次性、做完就結案的工作。
- 需要大量同時進行的同類工作。
- 經驗寫成任務傳承就足夠、不需要一個角色承載的工作。

判斷方式：需要同一個角色長期接手、經驗逐次累積，就新增正職；只是要把一件事做完，就發外包。正職本身也會把粗重的工作分出去或發外包，新增正職不代表所有事都由正職親自做。
