# 傳承條目怎麼寫：四個例子

這一頁是給**要寫一條傳承（lore）條目的成員**看的。開機說明裡有規格與那道門檻，這裡放的是**例子** ——
一條活下來的，加三條被負責人當場打掉的，每條附他退它的**逐字原話**。

> 🔴 **三條被退的比那條好的有用。** 那三條是寫的人從一整天的工作裡挑出來、當成「最值錢」交上去的
> —— 他寫每一條的時候都覺得自己有洞見。下一個人會犯的正是同一個錯：**寫給自己看，不是寫給下一個人看。**

⚠️ **這份的來源很窄**：全部來自一個成員（O-197）一個工作日的四條。等真的有幾十條寫進來之後，
例子應該換成從真實資料裡挑的，不要一直用這幾條。

---

## 一、那把尺（兩句話，都是負責人的）

**第一面 —— 給沒跟著你做的人看**：

> 把它給一個完全沒有跟著你做這件事的人看，**他知道下一步要做什麼嗎？**

**第二面 —— 推得出來就不要寫**：

> 換一個有能力的 agent，**它自己推得出來嗎？推得出來就不要寫。**

⇒ 推得出來的（通則／心法／common sense）不進傳承；推不出來的（這個系統的事實、工具的陷阱、
某人的偏好、真的踩過的坑）才進。

🔑 **兩面要一起用。** 只用第一面，會放進一堆「可執行但誰都知道」的東西；
只用第二面，會放進一堆「很特殊但讀完不知道幹嘛」的東西。

---

## 二、活下來的那一條

> 🔴 **v8 起，標題是獨立的一格（`heading`），第 1 格不再兼任標題。**
> `heading` 寫的是「**發生了什麼**」（不得是祈使句，上限 140 個 Unicode rune，中文一個字算 1）；
> 第 1 格 `trigger` 寫的是「**我要做 X**」，是讀者從哪一軸找到這條條目。兩句話不是同一句。

- **標題（`heading`，發生了什麼）**：用「畫面資料對得上」判斷成前端接了真後端，結論是錯的
- **第 1 格 `trigger`（什麼時候要記起來）**：我要確認一個 OffiCraft 前端畫面接的是真後端，還是假資料
- **第 2 格 `content`（內容）**：這個前端**預設就是假資料**（要在編譯時明確設旗標才接真後端，
  而其中一支打包腳本沒設），假資料模式下畫面完全正常。
  **怎麼判斷：看有沒有出現登入頁** —— 真後端會要你登入，假資料模式下登入頁根本不會出現。
  ⚠️ 不要用「畫面上的資料跟資料庫對得上」判斷：那份假資料是照真站做的，連對象名字都一樣。
- **第 4 格 `impact`（原本想達成什麼、實際變成什麼）**：我用「資料對得上」判斷成它接了真後端，結論是錯的。

  ⚠️ v8 把舊的「之前發生過什麼問題」改名成 `impact`，問的東西也換了 —— 舊的問**起因**，
  這一格問**後果**：原本想達成什麼、實際變成什麼。那件壞事其實沒發生（護欄先擋下來了）就寫
  「沒有發生，因為…」，不要編一個沒發生的後果；真的填不出來就留白。

**它為什麼活下來 —— 它其實不是一條規則，是三個推不出來的事實：**

| # | 事實 | 為什麼推不出來 |
|---|---|---|
| 1 | 這個前端**預設**是假資料 | 這是這個 repo 的選擇，不是任何通則。換個專案就不成立 |
| 2 | 有一支打包腳本**忘了設旗標** | 這是一個具體的疏漏，只能踩到 |
| 3 | 「資料對得上」**不具鑑別力**，「有沒有登入頁」才具 | 假資料是照真站做的 —— 不去比對根本不會知道 |

🔑 **注意第 3 點的形狀**：它同時給了**一個會騙你的檢查**和**一個真的有效的檢查**。
一條記憶如果只給後者，下一個人還是會先去用前者。

## 三、三條被打掉的，三種不一樣的死法

### 3.1 「讀到『夠用』就停」 ⇒ 廢話

| | |
|---|---|
| **負責人逐字** | 「讀到「夠用」就停 → **這是廢話**」 |
| **死在哪** | **描述的是心理狀態，不是動作。** 讀完不知道下一步要做什麼 |

回頭找它背後有沒有一件推不出來的事實 —— **沒有**。它從頭到尾就是作者對自己當天工作習慣的一句評語。
⇒ **處置：丟掉。不是改寫，是丟掉。**

🔴 **這是最容易漏掉的一種**：它讀起來很像一條經驗，因為它確實是作者的經驗。
但**「我的感受」不是「這個系統的事實」。**

### 3.2 「一個兩種世界都成立的檢查」 ⇒ 抽象標題

| | |
|---|---|
| **負責人逐字** | 「一個兩種世界都成立的檢查 → **完全看不懂要做什麼**」 |
| **死在哪** | **抽象標題。** 把一個具體的坑，壓縮成一個只有作者自己看得懂的名字 |

> 📌 **「抽象標題」是這種死法的名字，不是在指 v8 的 `heading` 那一格。** 這條被打掉的時候，
> 被退的是第 1 格；同一個毛病寫進 `heading` 一樣會死。

**這條救得回來** —— 它背後有三個真的推不出來的事實。**它重寫之後就是第二節那條活下來的。**

**同一條的兩個版本並排（這是整頁最該看的一格）：**

| | 原本寫的 | 重寫之後 |
|---|---|---|
| **第 1 格 `trigger`** | 一個兩種世界都成立的檢查 | 我要確認一個 OffiCraft 前端畫面接的是真後端，還是假資料 |
| **形狀** | 一個概念的名字 | **「我要做 X」** |
| **讀者讀完** | 知道有個道理，不知道要幹嘛 | 知道現在要去看畫面上有沒有登入頁 |
| **自己推得出來嗎** | 「有些檢查沒有鑑別力」—— 可以推 | 「這個前端預設是假資料」—— **推不出來** |
| **命運** | 被打掉 | 唯一活下來的 |

🔑 **兩個版本背後是同一件事。差別只在：一個講的是作者學到的道理，一個講的是這個系統的事實。**
⇒ **道理是從事實推出來的。下一個人拿到事實，自己也推得出那個道理。所以該留的是事實，不是道理。**

### 3.3 「在兩個動機之間二選一之前，先找那個讓二選一消失的事實」 ⇒ common sense

| | |
|---|---|
| **負責人逐字** | 「…先找那個讓二選一消失的事實 → **這個本身就是一個 common sense**」 |
| **死在哪** | **有能力的人本來就會做。** 佔了位置，但不帶新資訊 |

**這條不該救。** 跟 3.1 不一樣：3.1 是**背後沒有事實**，這條是**背後的事實太普通**。
⇒ **處置：丟掉。**

🔴 **但它有一個真實的來源，而那個來源本身才該進傳承**：作者當時在追一個問題，
卡在「這是被核可的改動，還是悄悄漂移的」二選一。**答案是去查 commit 日期，一查就完了，
而他先開口問了一輪才去查。**
⇒ 可以寫的不是「先找讓二選一消失的事實」（common sense），
而是「**這個系統裡，『是不是刻意改的』這個問題，查 commit 日期就能答完**」—— 那是這個系統的事實。

## 四、三種死法 ⇒ 三種不同的處置

```
這條記憶背後，有沒有一件「換個有能力的 agent 也推不出來」的事實？
├─ 沒有事實，只有我的感受        ⇒ 丟掉（3.1）
├─ 有事實，但那事實誰都知道      ⇒ 丟掉（3.3）
└─ 有事實，而且推不出來
   ├─ 我寫的是那個事實           ⇒ 留（第二節）
   └─ 我寫的是我從它推出的道理   ⇒ 改寫成事實再留（3.2）
```

| 死法 | 症狀 | 例子 | 處置 |
|---|---|---|---|
| **廢話** | 描述心理狀態，讀完不知道要做什麼 | 3.1 | **丟掉** |
| **抽象標題** | 只有作者看得懂的名字 | 3.2 | **改寫**成背後的事實 |
| **common sense** | 有能力的人本來就會做 | 3.3 | **丟掉**（但它的來源可能有一條該寫的） |

## 五、填完之後的自檢

1. **標題後面加一個問號唸一次。** 唸起來像在追認一個已經給了答案的話 ⇒ 它是主張，重寫成「發生了什麼」。
2. **把第 2 格拆成三句唸一次**：機制／實例／動作。**缺一段就是沒寫完。**
3. **把標題裡的每個名詞與數字，逐個去第 2 格找。** 找不到就是標題超出了內容的射程。

⚠️ **不要再加第四道。** 實測過：加判斷型的檢查（要人判斷「這樣寫對不對」）**整份規則會退步** ——
那些檢查會跑、會逐字寫下問答、然後答錯、然後打勾。**有效的檢查是動作型的。**

---

## 六、這一頁沒做到的（照實列）

1. **來源只有一個成員的一天。** 四個樣本、一個作者、一個工作日。
   **這不足以說「傳承的三種死法就是這三種」** —— 它只證明這三種真的發生過。
2. **沒有辦法證明「改寫之後那條就是對的」。** 那條「前端預設是假資料」之所以被當成好例子，
   是因為**負責人沒有打掉它**，不是因為有誰驗過它會不會幫到下一個人。**它還沒被使用過。**
3. **第四節那棵判斷樹是從三個樣本歸納的**，負責人沒有看過、沒有表態。
   它現在的地位是「一個提案」，不是規格。
4. 🔴 **這把尺擋不到「寫得很好、但結論是錯的」那一種。**
   反例是同一個作者同一天寫的另一句：「試用站的資料庫是從正式站複製來的」——
   它有具體事實、有三筆真紀錄、形狀完全合格，**而結論是錯的**。
   這一頁裡的每一條檢查都會放它過去。**那一層只能靠人審。**
