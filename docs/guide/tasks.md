# 追蹤任務進度

讀完這頁，你能看懂任務卡上的狀態與步驟、知道成員什麼時候會停下來等你，並在需要時凍結、終止、轉派或結案一張任務。

## 任務怎麼產生

你在聊天室交代一件事後，要不要開成任務由成員自己判斷，簡單的事成員可能直接在聊天室回覆。想用任務追蹤，交代時直接說「建一張任務」。

成員的預設工作守則要求，建立任務之前先開一張請示卡請你確認。這是成員照守則做的事（守則在 **設定 › 全域情境**），不是系統強制的步驟。卡上會寫明：

- 任務名稱與要解決的問題
- 任務類型：照哪一本任務手冊做
- 完成條件（AC）：做完時可以看到、可以檢查的結果
- 由誰來做，以及用哪台機器、哪個模型

你確認後，成員再建立任務。想改其中任何一項，直接寫在回覆裡，成員會照你確認的內容建立。

任務由誰來做，由任務手冊的「負責成員」決定。沒有適用的手冊時，由開任務的成員自己做，任務卡上的任務類型顯示「自由代辦」。任務手冊怎麼寫，見 [讓 AI 照 SOP 做重複的事（任務手冊）](sop.md)。

外部事件（例如 Slack、GitHub 送來的通知）和定期訊息也可能讓成員開任務，流程一樣。

## 在任務頁找到任務

![任務卡](assets/cockpit-task.png)

「任務」分頁先列還沒結案的任務，再列已結案的任務。分頁上的數字是還沒結案的任務數。

上方的篩選列可以依負責人、狀態、到期日等條件篩選。一開始只列出還沒結案的任務，要看已結案的任務，清除篩選即可。

每張任務卡上最常看的是：

- **狀態**：任務走到哪個階段，見下一節。
- **負責人**：現在做這張任務的成員。
- **到期日**：快到期或已逾期時會變色提醒。可以直接在任務卡上設定。
- **步驟 完成數/總數**：做完幾步、總共幾步。

要跟負責人說話，直接用任務卡上的訊息框傳訊息。

任務卡各欄位的說明見 [介面說明](interface.md) 的「任務」。

## 任務的狀態

| 狀態 | 意思 |
| --- | --- |
| 尚未執行 | 任務已建立，還沒開始做。 |
| 進行中 | 成員正在推進。 |
| 等我回覆 | 有一張綁在步驟上的請示卡在等你回覆，任務停在那一步。 |
| 等待外部 | 在等第三方：權限還沒開、對方還沒回信、時間還沒到。 |
| 可結案 | 所有步驟都完成了，正在等負責人收尾。 |
| 已完成 | 已結案。 |
| 終止 | 已結案，任務被中止，不再做。 |
| 重複 | 已結案，任務和另一張任務是同一件事。 |

前五種狀態會隨步驟的進度自動改變，不需要任何人設定。後三種是結案後的狀態；**任務不會自己結案**，一定要有人結案。

任務卡上有時會多一個「轉派中」，表示任務正在換負責人。

## 步驟與完成定義

負責人會把任務拆成幾個步驟，列在任務卡的「工作流程」裡。每個步驟有一句完成定義（DoD），說明做到什麼程度才算完成。

任務停著沒動時，先看負責人在步驟上留的備註，通常比再問一次快。

## 什麼時候會停下來等你

有些步驟需要你決定、核可或驗收，成員規劃時會把這些步驟設成**關卡**。任務卡一開始就會在關卡上標出「等我回覆」，讓你先知道哪幾步會需要你。走到關卡時，成員會開一張請示卡，任務變成「等我回覆」。

關卡之外，成員在任何一步遇到需要你決定的事，也會當場開請示卡，停下來等你。

怎麼回覆請示卡，見 [交代工作與回覆請示卡](daily.md)。

## 凍結、終止、標記重複與轉派

- **凍結**：在任務卡的「優先權」選「凍結」，成員就停止推進這張任務。成員要恢復一張被凍結的任務前，會先開卡問你。
- **終止**：點任務卡上的狀態標籤選「終止」。任務會結案為「終止」，**無法恢復**。
- **標記重複**：點任務卡上的狀態標籤選「標記重複」，並指出原本那張任務。任務會結案為「重複」，**無法恢復**。
- **轉派**：在任務卡「負責人」旁選「轉派…」，可以轉給另一位成員或轉外包。

## 產物

成員把要給你看、要你驗收的成果放在任務卡上，稱為**產物**，可以是檔案、圖片或連結。文字檔可以看每一版改了什麼。

**移除產物會永久刪除舊版本**，目前的檔案則會保留。

從產物打開的文件，也可以直接寫註解送回負責人，做法見 [交代工作與回覆請示卡](daily.md)。

## 結案

所有步驟完成後，任務變成「可結案」。負責人會把成果放成產物，再開一張請示卡請你驗收。你驗收通過後，負責人才把任務結案為「已完成」。你還沒回覆或要求修改時，任務不會結案。

步驟還沒做完、但你決定不再繼續時，可以點任務卡上的狀態標籤選「強制結案」。**強制結案無法復原**。

想知道負責人收尾時還會做哪些事，見 [架構與運作原理](architecture.md) 的「任務結案前負責人做什麼」。
