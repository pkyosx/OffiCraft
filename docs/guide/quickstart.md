# 你的第一個辦公室

讀完這頁，你能從第一次打開控制台開始，交出第一件事、回覆第一張請示卡，一路看到任務結案。全程大約十分鐘。

這頁假設安裝腳本已經跑完，並印出了一次性設定連結。還沒安裝的話，先看 [安裝、升級與移除](install.md)。

剛裝好時，工作室裡只有兩個人：你，和你的助理 **Mira**。

---

## 第一步：打開控制台，設定登入密碼

安裝完成時，終端機會印出一行一次性設定連結：

```
http://127.0.0.1:7755/?code=…
```

在同一台機器上用瀏覽器打開它，會看到「設定管理密碼」畫面，啟用碼已經自動填好。輸入兩次新密碼（至少 8 個字），按「開始使用」。

- 一次性設定連結只能用一次。密碼設好後，連結裡的啟用碼立即失效。
- 之後要進控制台，打開 `http://localhost:7755`，用密碼登入。
- server 只接受本機連線，這一點不能改，其他裝置直接連不進來。要從手機或其他電腦使用，請先看 [保護你的工作室](security.md)，設好強密碼與兩步驟驗證或通行密鑰，再照 [在手機上用](mobile.md) 把本機的 7755 埠轉出去。

密碼設好後，server 會自動把這台機器的 warden 裝好，並喚醒 Mira，你不需要自己操作。如果其中一步失敗，控制台上方會出現「自動設定沒有全部完成」的橫幅並寫明原因，常見原因與處理方式見 [常見問題與排解](troubleshooting.md)。

---

## 第二步：認識 Mira

登入後你會在「辦公室」分頁。左側「辦公室成員」分成「正職」與「外包」兩個頁籤，Mira 在「正職」裡。

Mira 頭像右下角的圓點表示她的上線狀態：

| 狀態 | 意思 |
| --- | --- |
| 喚醒中 | 正在啟動 |
| 線上 | 已經可以對話 |
| 停止中 | 正在收尾、準備下線 |
| 已停止／離線 | 目前沒有在執行 |

第一次進來時，Mira 通常正從「喚醒中」變成「線上」。等她變成「線上」就可以開始。

在線上時，聊天室標題列還會顯示她目前的工作狀態：工作中、等待中或閒置。

Mira 是你的助理，負責工作室的日常維運，也接你交代的事情。她底下是一個跑在 tmux 裡的 Claude Code 或 Codex session，用的就是你機器上的 `claude` 或 `codex`，你原本的設定照常有效。

---

## 第三步：傳第一則訊息

點 Mira，右側會打開和她的聊天室。傳一句話試試，例如：

> 你好，先自我介紹一下，順便告訴我這間工作室現在有誰。

送出後，Mira 會在聊天室回覆你。幾件事先記住：

- 你和成員之間只透過控制台的聊天溝通。成員看不到你的終端機，你也看不到成員的終端機畫面。
- 成員的回覆會盡量精簡，只講重點。需要細節時直接要她展開。
- 聊天可以傳截圖、設計稿、文件等附件，成員也會把做好的成果用附件傳回來。

聊天的完整操作（附件、@ 成員、引用回覆）見 [交代工作與回覆請示卡](daily.md)。

---

## 第四步：交出第一件事

交一件需要好幾個步驟、值得追蹤的事，例如：

> 幫我把 `~/some-repo` 的 README 從頭讀一遍，列出三個最該修的問題，各附「在哪、為什麼、建議怎麼改」。

需要追蹤的事，Mira 會建成一張任務。建立之前，她會先開一張請示卡，列出任務名稱、要解決的問題、完成條件、由誰執行，請你確認。

1. 打開「請示」分頁，或直接在聊天室裡看這張請示卡。
2. 內容沒問題就選同意的選項；想調整範圍或完成條件，直接打字回覆。
3. 你確認後，Mira 建立任務。

打開「任務」分頁，可以看到這張任務卡：

- 任務拆成多個步驟，每個步驟寫明完成定義，也就是做到什麼程度才算完成。
- 卡上看得到目前做到哪一步、每一步的狀態，以及每一步的備註。

任務狀態、步驟與完成定義的完整說明見 [追蹤任務進度](tasks.md)。

---

## 第五步：回覆一張請示卡

做到某一步，如果有事只有你能決定（要不要動手、選哪個方向、能不能花這筆錢），Mira 不會替你決定。她會開一張**請示卡**，那一步的狀態變成「等我回覆」，等你回覆。「請示」分頁上的數字是還在等你回覆的卡數。

打開請示卡，你會看到：

- 一個問題，以及做判斷需要的背景與取捨。
- 幾個選項。標著「AI 建議」的是 Mira 推薦的做法，不一定排在第一個。
- 選項前面是序號的是**單選卡**：點一個選項就直接送出。
- 選項前面是勾選框的是**多選卡**：「AI 建議」的選項已經預先勾好，可以增減，勾完再送出。
- 也可以在「輸入回覆…」直接打字回覆。單選卡上已經打好的文字，會和你點的選項一起送出。

回覆後，那一步回到「進行中」，Mira 接著做下去。已回覆的卡在「近期已處理」裡，可以按「重新決定」改答案。

請示卡的其他操作（引用原文、標為過期）見 [交代工作與回覆請示卡](daily.md)。

---

## 第六步：看任務結案

所有步驟做完後，任務狀態變成「**可結案**」，卡上會寫「所有步驟都完成了，正在等負責人收尾。」這時任務還沒有結束：Mira 會把交付物（報告、PR 連結、產出的檔案）放到任務卡的產物上，再開一張請示卡請你驗收。你回覆驗收通過後，Mira 才把任務結案；你要求修改時，它會改完再請你驗收一次。結案後狀態變成「**已完成**」，任務移到「已結案」區。

任務不會因為時間到而自動結案。如果負責的成員已經無法收尾，你可以在任務卡的狀態選單選「**強制結案**」；強制結案無法復原。

到這裡，你已經走完一次完整流程：

```
交代一件事 ─> 確認任務內容 ─> 成員拆成帶完成定義的步驟 ─> 需要你決定時開請示卡 ─> 你回覆 ─> 步驟全部完成（可結案）─> 收尾並結案（已完成）
```
