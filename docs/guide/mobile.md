# 在手機上用

讀完這頁，你能讓手機連上控制台、在手機上登入、把控制台加到主畫面並收到推播通知，在手機上回覆請示卡、看任務進度和跟成員聊天。

![手機上的請示頁](assets/cockpit-mobile-ask.png)

![手機上的辦公室頁](assets/cockpit-mobile-office.png)

主導覽的分頁依序是辦公室、請示、任務、傳承、密鑰、監控、使用說明；手機上分頁列放不下時可以左右滑動。

## 讓手機連得到控制台

控制台**只接受裝 OffiCraft 的那台 Mac 本身的連線**，這一點不能改。手機要連，需要用轉發工具，把那台 Mac 上控制台使用的 7755 埠轉出去。常見的做法有兩種：

- **cloudflared 這類 tunnel 工具**：給你一個公開的 HTTPS 網址，手機在任何地方都連得到。
- **Tailscale 這類私有網路的轉發功能**（例如 `tailscale serve`）：只有你自己的裝置連得到。只加入私有網路、不做轉發，手機連不到。

**開放之前，先設好夠強的密碼和兩步驟驗證。** 轉發開通後，任何知道網址的人都能打開登入頁試著登入。也不要用沒有 HTTPS 的方式對外開放。設定方式見 [保護你的工作室](security.md)。

## 第一次在手機上登入

1. 在手機的瀏覽器打開轉發後的網址。
2. 輸入密碼；有開兩步驟驗證時，再輸入驗證碼。

登入後，可以在手機上新增一把通行密鑰，之後用 Face ID 或指紋登入。**通行密鑰要在手機上、用轉發後的網址打開控制台時新增**；在電腦上用 `localhost` 網址新增的通行密鑰，手機上不能用。做法見 [保護你的工作室](security.md) 的「通行密鑰」。

不想在手機上打密碼和驗證碼時，可以在那台 Mac 上產生一條一次性登入連結，傳到手機上打開就直接登入。做法見 [保護你的工作室](security.md) 的「一次性登入連結」。

## 加到主畫面

iPhone 或 iPad：

1. 用 Safari 打開控制台網址。
2. 點下方工具列的「分享」。
3. 選「加入主畫面」，取一個你認得的名字，按「加入」。

Android（Chrome）：右上角選單選「加到主畫面」。

之後從主畫面點開，控制台會以獨立 App 的形式全螢幕開啟，沒有網址列。

## 開啟推播通知

開啟後，有新訊息或需要你決定的請示時，這台裝置會收到通知。點通知會回到對應的聊天室或請示頁。

1. 點右上角頭像，在「通知信箱」填一個信箱。
2. 點頂端的鈴鐺圖示（「開啟通知」）。
3. 瀏覽器詢問時選「允許」。

要注意：

- **iPhone、iPad 要先加到主畫面**，從主畫面打開控制台後才能開啟通知，系統也要是 iOS／iPadOS 16.4 以上。
- 每台裝置要各自開啟一次。
- 通知信箱會提供給瀏覽器的推播服務，請用可以公開的信箱。

想知道更多細節，例如鈴鐺上的斜線代表什麼、鈴鐺沒有出現時怎麼辦，見 [介面說明](interface.md) 的「頂列」。

## 手機上的畫面

手機和電腦的功能相同，只是一次只顯示一個區塊：

- 「辦公室」先顯示成員名單。點成員進入聊天室，按「返回成員」回到名單。
- 「請示」可以直接回覆請示卡：序號開頭的是單選卡，點一下選項就送出；勾選框開頭的是多選卡，勾好再送出。
- 「任務」看每張任務的狀態、步驟和備註。
- 聊天可以傳照片、貼上截圖，也可以打開成員傳來的圖片與文件。

各項操作的說明見 [交代工作與回覆請示卡](daily.md) 和 [追蹤任務進度](tasks.md)。
