# 管理 AI 帳號與用量

讀完這頁，你能在「監控」分頁看到每個帳號用了多少、估計花了多少，以及每位成員用的是哪個帳號與模型，並在這裡替機器登入帳號、升級 Claude Code。

## 用量算在誰的帳號上

成員用的是你自己的 Claude 與 Codex 帳號，用量與費用都算在你的帳號上。對話內容照常送到 Anthropic 或 OpenAI。

## 在「監控」分頁看用量

打開「監控」分頁就看得到：

- **帳號資訊**：每個帳號在「5 小時窗」與「7 天窗」用了多少。用得太快時，帳號會標「過熱」；用完時會標「已達上限」，並寫出重置時間。
- **估計**：每個帳號累計的估計花費。
- **AI 會話**：每位成員在哪台機器、用哪個帳號與模型、估計花了多少。

各欄位的完整說明見 [介面說明](interface.md) 的「監控」。

## 用量數字從哪裡來

每台機器的 warden 約每 5 分鐘、以及每次啟動 Claude 成員時，拿這台機器上成員會用的那份 Claude 登入直接問 Anthropic：這份登入是哪個帳號、5 小時窗與 7 天窗各用了多少。「帳號資訊」顯示的就是這個答案，數字旁的「量於 X 前」是量的時間。

- 問不到時（例如登入已過期、Anthropic 沒有回應），帳號會寫「用量未知」與原因，不會拿舊的或估計的數字代替；認不出是哪個帳號時，原因寫在「機器資訊」的 Claude 欄。
- 一個帳號已經沒有任何機器登入時，保留最後一次量到的數字與時間，直到那個時窗重置；別的帳號的數字不會蓋過它。
- 在 macOS 上，同一台機器可能同時存著兩份 Claude 登入：鑰匙圈裡一份，`~/.claude/.credentials.json` 一份（例如從 ssh 登入時只寫得進檔案）。成員用的是鑰匙圈那份，這裡量的也是那份；鑰匙圈裡沒有這個項目、或讀出來的不是登入資料時才用檔案。鑰匙圈項目讀得出來、裡面卻沒有可用的登入時，Claude Code 也不會改用檔案，所以這裡寫「用量未知」，不會改量檔案那份。
- warden 只讀登入、不會更新或改寫它，也不會把登入內容送到 OffiCraft server。

## 登入帳號與升級 Claude Code

「監控」分頁的「機器資訊」列出每台機器，點 Claude 或 Codex 欄的版本號會打開選單：

- **登入**：替這台機器登入 Claude 或 Codex 帳號，這台機器上的成員就用這個帳號。已經登入時，完成後會換成新登入的帳號。
- **升級 Claude Code**：升級這台機器上成員使用的 Claude Code。

## 換 Claude 帳號時，正在執行的成員

Claude 成員啟動時，warden 用上面同樣的方式查出它那份登入是哪個帳號，成員從那一刻起就一直算在這個帳號上，直到它重新啟動為止；查不出來時（例如這台機器的成員閒置太久、登入的存取權杖已過期，要等成員自己的 Claude Code 執行時更新它），這位成員的帳號欄是空的；之後 warden 第一次查到這台機器那份登入的帳號時，就把這位成員記到那個帳號上，每次啟動只補記這一次。補記之前的估計花費不算在任何帳號上。機器改登入另一個帳號後，已經在執行的成員仍用舊帳號，它的用量與估計花費也繼續算在舊帳號上；這位成員重新聚焦、喚醒或重新上線之後，才改用新帳號。

這段期間「AI 會話」的帳號欄會在舊帳號下方寫「仍用舊帳號，重新聚焦後換新帳號」。想讓成員馬上改用新帳號，就對它按「重新聚焦」。換帳號之前已經記在帳號上的花費不會搬動。

## 用量用完時

帳號的用量用完時，用這個帳號的成員名字旁會出現驚嘆號，原因寫「已達用量上限」，等重置時間到就會恢復。驚嘆號的其他原因與處理方式，見 [增加成員與發外包](members.md) 的「看懂成員的狀態」。
