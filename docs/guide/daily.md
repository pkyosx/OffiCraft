# 交代工作與回覆請示卡

讀完這頁，你能在聊天室把工作交給成員、回覆成員開給你的請示卡，並直接在成員交來的文件上寫意見送回去。

## 在聊天室交代工作

到「辦公室」分頁，在左側「辦公室成員」點一位成員，右側就是你和這位成員的聊天室。手機上一次只顯示一邊，按「返回成員」回到名單。

- 在輸入框打字後按「送出」。電腦上按 Enter 也會送出，Shift+Enter 換行；手機上 Enter 是換行，要按「送出」。
- 按「附加檔案」可以附檔，也可以直接貼上截圖。單張圖片上限 20 MB，一則訊息能附的檔案數有上限，超過時畫面會寫出上限。
- 聊天室上方的「檔案與圖片」列出聊天室裡出現過的圖片和檔案，可以「依上傳者篩選」。
- 成員離線時，輸入框上方會寫「目前離線中 — 訊息會排隊，或立即喚醒上線」。你可以直接留言，成員上線後就會讀到；也可以按「喚醒」讓成員上線。
- 往上捲讀舊訊息時，按「回到最新訊息」回到最底下。

把一件事交給成員時，直接用一般的話說清楚要什麼結果即可。成員判斷這件事需要開成任務時，會先開一張請示卡請你確認任務內容、完成條件和由誰執行，你確認後才會建立任務。任務建立之後怎麼追，見 [追蹤任務進度](tasks.md)。

## 用 @ 提到某位成員

在聊天輸入框、任務卡的訊息框或請示卡的回覆框打 `@`，會出現「提及成員」清單：

- 正職顯示名字與角色；外包顯示「外包 · 代號」，有任務時一併顯示任務編號與標題。
- 可以用名字、角色、任務編號或任務標題篩選。用上下鍵移動，Enter、Tab 或點一下選取，Esc 關閉清單。
- 送出後，訊息裡的名字可以點，點了會打開那位成員的詳細資料。從「請示」或「任務」分頁點進去時，返回按鈕寫「返回請示」或「返回任務」，按下會回到那一頁並只顯示原本那張卡，卡片保持展開；清空頁面上的編號篩選，就回到完整清單。

提及只是在訊息裡標出一個人，**被提到的成員不會收到通知**，訊息也只會送給目前聊天室的成員。要讓另一位成員知道，請到該成員的聊天室傳訊息。

## 回覆某一則訊息或其中一段

- **回覆這則**：在訊息旁按「回覆這則」，輸入框上方會出現引用列（「正在回覆 名字」）。送出後，你的訊息上方會顯示「引用 名字」，點「看原訊息」會捲回被引用的訊息。按「取消回覆」可以撤掉引用。
- **回覆這段**：在一則訊息裡選取一段文字，旁邊會出現「回覆這段」，按下去只引用你選取的文字。選取的字數有上限，超過時會顯示「選取超過 N 字」。

## 成員之間的對話

成員之間互傳的訊息也會出現在聊天室裡，連續的幾則會收合成一列「N 則成員間對話 · 展開」。按下去展開，按「收合成員間對話」再收起來。

## 看成員現在的狀態

交代工作前，先看成員名字前面的狀態圖示：工作中、等待中、閒置或離線。名字旁邊出現驚嘆號，表示這位成員目前無法正常呼叫模型，例如未登入、登入失效或已達用量上限，點驚嘆號會列出原因。每個圖示的意思與處理方式見 [增加成員與發外包](members.md)。

## 回覆請示卡

成員遇到只有你能決定的事（要不要做、選哪個方案、需要你先完成某個動作），會開一張請示卡，然後停下來等你。請示卡會出現在三個地方，在任何一處回覆都一樣：

- 「請示」分頁。分頁上的數字是還在等你回覆的卡片數。
- 成員的聊天室裡，夾在訊息之間。
- 任務卡上的「請示」區塊，按「在聊天室回覆」會跳到聊天室裡的同一張卡。

卡片上依序寫背景、要你做什麼、影響和建議，讀完卡片本身就能回答，不需要回頭翻聊天紀錄。卡片和任務有關時，上方會有「查看任務詳情」；「跳到原訊息」會帶你到聊天室裡開卡的訊息。

**作答方式：**

- **單選卡**：選項前面是序號 1、2、3、4。點一下選項就直接送出，送出後無法撤回。最多 4 個選項。
- **多選卡**：選項前面是勾選框，可以勾好幾項，畫面會寫「已選 N 項」，勾好再按送出。打開時已經先勾好標著「AI 建議」的選項，不同意就取消勾選。最多 20 個選項。
- 標著「AI 建議」的是成員推薦的選項，看標籤，不看位置。
- 也可以在「輸入回覆…」直接打字回答。在單選卡上先打字再點選項，打的字會跟選項一起送出。

**只回答卡片上的某一段**：在卡片的問題內容裡選取一段文字，按「回覆這段」，回覆框上方會出現「引用原文」和你選取的文字，接著選選項或打字送出。成員會知道你的回答針對的是被引用的文字。按「取消引用」可以撤掉。

**改變決定**：回覆過的卡會移到「近期已處理」，可以按「重新決定」，重新選一個選項或直接打字改寫回覆。新的回答會取代舊的回答，成員會收到通知。「查看當初選項」可以看回當時的選項。

**標為過期**：問題已經不需要回答時（情況變了、已經改由別張卡處理），按卡片右上角的「標為過期」，再按「確認標為過期」。標為過期不算回答，也無法復原；成員會收到通知，如果問題還在，成員會重新開一張卡。「請示」分頁和聊天室裡的卡片都能標為過期。

**展開與收合**：聊天室裡的請示卡預設收合成一列，前面標著「待回覆」「已回覆」或「已過期」。點收合列展開；展開後點卡片的空白處就收合回去。

「近期已處理」只保留最近 24 小時內回覆或標為過期的卡片。還沒回覆的卡片不受 24 小時的限制，放多久都會留在「請示」。

## 在成員交來的文件上寫註解

從聊天附件、任務產物或訊息裡的連結打開 `.md`、`.txt`、`.log` 或 `.json` 文件時，標題列有一顆「註解」按鈕。

1. 按「註解」，畫面旁邊（手機上是下方）會出現「文件註解」清單。
2. 在文件裡選取一段文字，或在 `.md` 文件裡點一張圖片，按「加註解」，寫下意見後按「儲存」。可以加好幾則，每一則都能編輯或刪除。
3. 被註解的文字會標上底色，旁邊有「N 則註解」的標記；點標記會捲到清單上對應的註解，點清單上的原文會捲回文件裡的原文。
4. 寫完按「送出給 AI」。所有註解會合成一則聊天訊息，開頭是這份文件的連結，接著逐則列出原文與你的意見。

送出鈕上方寫著「送給：」哪一位成員：

- 在某位成員的聊天室裡打開的文件，送給該聊天室的成員。
- 從請示卡裡打開的文件，送給開卡的成員。
- 從任務卡或任務產物打開的文件，送給任務的負責人。

對方已經不在名冊上，或任務還沒有負責人時，無法送出，畫面會寫出原因。還沒送出的註解存在這台裝置的瀏覽器裡，關掉文件再打開還在；換一台裝置就看不到。

## 看成員改了什麼：比較連結

成員要讓你看一份東西改了哪裡時，會給你一個比較連結（以 `/diff?` 開頭）。點開會在原頁顯示前後兩份的差異：

- 「比對方式」可以切換「單欄」或「兩欄對照」，內容整份顯示，不摺疊。
- 兩側的標題寫著該側的內容來源：「版本 #N」是版本紀錄裡的某一版；「預設內容」是系統隨附的內容；「目前存檔內容（讀取於 …，之後會不一樣）」表示該側是讀取當下的內容，之後再打開可能不同。
- 點標題可以單獨看該側的原文，按「回到比較」回來。
- 某一側的東西已經被刪除時，畫面會寫「這個比較有一側已經不在了」。

比較連結預設要登入才看得到。要給沒有帳號的人看，按「複製對外連結」，複製出來的連結不用登入就能打開。對外連結沒有期限，也無法單獨收回，請只在必要時使用；讓它失效的方法見 [保護你的工作室](security.md)。

## 用網址只看某一張任務或請示卡

在網址後面加上編號，頁面就只顯示該編號的任務或請示卡：

- 任務：`/#tasks/任務編號`
- 請示卡：`/#replies/card/請示卡編號`

成員在聊天裡給你的任務或請示卡連結就是這種寫法，點了直接打開該任務或請示卡。打開後，頁面上方的「任務編號」或「請示卡編號」欄位會填好編號，清空欄位再按 Enter 就回到完整清單。編號不存在時會顯示「沒有符合篩選條件的任務」（或「…的請示」）；連不上伺服器時，畫面會寫「暫時無法確認…是否存在，請稍後再試」或載入失敗，不會說成找不到。

## 訊息與文件支援的 Markdown

聊天訊息、請示卡、任務說明與步驟、角色定義、任務手冊和這份使用說明，都用同一套排版。支援以下寫法，其他寫法會原樣顯示成文字：

- 標題：`#` 到 `######`（`#` 後面要有空白）。
- 清單：`- `、`* ` 開頭的項目，`1. ` 開頭的編號清單；項目底下縮排的內容會歸在該項目之下。
- 引用：`> `。引用的第一行寫 `> [!NOTE]`（或 `TIP`、`IMPORTANT`、`WARNING`、`CAUTION`）會變成提示框。
- 程式碼：`` `行內` `` 與用 ``` 圍起來的區塊。
- 表格：標題列加上 `|---|` 分隔列。
- 分隔線：單獨一行三個以上的 `-`、`*` 或 `_`。
- 粗體：`**粗體**`。
- 連結：`[文字](網址)`，網址可以是 http、https、mailto，或以一條斜線開頭的站內路徑（例如 `/#tasks/T-12`）。直接貼上的 http／https 網址和 `/diff?` 比較連結也會自動變成連結。
- 在符號前加反斜線（例如 `\>`）會讓它顯示成一般文字。

不支援：`+ ` 開頭的清單、`*斜體*`、`~~刪除線~~`、`1) ` 這種括號編號。

聊天訊息裡按一次換行就是換行；其他地方要空一行才會分段。
