# 把帳號金鑰交給成員用（密鑰）

讀完這頁，你能把 API token、部署金鑰這類機密存進 OffiCraft，讓成員在需要時取用，而機密的內容不會出現在聊天、請示卡或任務紀錄裡。

## 新增密鑰

1. 點上方導覽列的「密鑰」分頁。
2. 按「新增密鑰」。
3. 填「名稱」與「值」。有使用限制時，寫在「備註」，例如「只用於發布到 npm，不要拿來推 git」。
4. 按「儲存」。

儲存後，清單上多出一張卡片。卡片上有一串 `sec-` 開頭的密鑰 ID，點一下就會複製，方便貼給成員。

**值存進去之後，控制台不會再顯示。** 你自己在控制台上也讀不回原本的值。

只有你能新增、修改和刪除密鑰。所有在職的成員，正職和外包，都能取用。

## 交代成員使用某一筆密鑰

在聊天或任務裡告訴成員要用哪一筆。最明確的方式是直接給密鑰 ID，例如：

> 用密鑰 sec-aaaaaaaaaaaa 發布這個套件到 npm。

沒給 ID 時，成員會依名稱和備註找出對應的那一筆；判斷不出來時，會開請示卡請你指定。成員使用前會先讀備註，所以有使用限制就寫在備註裡。

**不要把值直接貼在聊天裡。** 聊天內容會留在紀錄中，也會被帶進成員的記憶。存成密鑰後，成員取用時值不會顯示出來。

## 修改與刪除

- **修改**：按卡片右上角的編輯圖示。只改名稱或備註時，值那一格留空，原本的值會保留。要換值，就把新值完整填一次。
- **刪除**：按卡片右上角的刪除圖示並確認。刪除後**無法復原**，成員之後用這筆密鑰 ID 取用會失敗。

## 看密鑰有沒有被用過

卡片上的「最後存取」是成員最後一次取用這筆密鑰的時間；從沒被取用過時顯示「尚未使用」。用途：

- 確認成員真的用了你交代的那一筆。
- 找出很久沒人用的密鑰，考慮刪除。
- 發現不該被用到的密鑰最近有人取用時，到對應的服務撤銷並換新金鑰，再回 OffiCraft 更新值。

想知道更多細節，例如名稱與值的長度上限、成員取用密鑰的指令，見 [介面說明](interface.md) 的「密鑰」和 [架構與運作原理](architecture.md) 的「成員怎麼取用密鑰」。

## 一定要另外保存 vault.key

密鑰的值是用一個叫 `vault.key` 的檔案加密的。**資料庫備份不包含 `vault.key`**，請另外保存；少了 `vault.key`，從備份還原後的密鑰就無法取用。保存與還原的做法見 [保護你的工作室](security.md) 的「密鑰與 vault.key」。
