# 保護你的工作室

讀完這頁，你能管理誰進得了控制台、在開放手機或外部連線之前做好準備，並知道哪些金鑰與檔案需要保管好。

控制台背後就是你的整間工作室：成員在你的電腦上有很大的操作權限，「密鑰」分頁裡存著你交給成員的帳號金鑰。所以要先設好登入控制台的方式，再考慮從外部連線。

---

## 開放外部連線之前

控制台只接受裝 OffiCraft 的那台 Mac 本身的連線，這一點不能改。要從手機或其他電腦使用，要用轉發工具把那台 Mac 的 7755 埠轉出去，做法見 [在手機上用](mobile.md)。

**轉發開通之前，先完成這三件事：**

1. 把登入密碼換成夠長、沒在別處用過的密碼。
2. 開啟兩步驟驗證，或改用通行密鑰登入。
3. 視需要把登入有效期調短。

**不要用沒有 HTTPS 的方式對外開放。** cloudflared 這類 tunnel 工具會給你一個公開的 HTTPS 網址，任何知道網址的人都能打開登入頁；Tailscale 這類私有網路的轉發功能（例如 `tailscale serve`）則只有你自己的裝置連得到。

開了公開網址之後，回呼端點（webhook）的網址也會一起對外。回呼網址不需要登入，拿到網址的人就能送事件給成員，所以只把回呼網址填在要串接的服務裡。網址外流時怎麼處理，見 [讓外部事件自動送給成員（回呼端點）](webhook.md)。

---

## 登入密碼

第一次打開控制台時設定的密碼，就是登入控制台的密碼，至少 8 個字。

**修改密碼**：點右上角頭像 › 帳號安全 › 修改密碼，輸入目前密碼與兩次新密碼，按「儲存」。改密碼後，其他裝置與分頁上已登入的控制台都會被登出，要用新密碼重新登入。

忘記密碼時，要在裝 OffiCraft 的那台 Mac 上執行指令重設，步驟見 [常見問題與排解](troubleshooting.md) 的「忘記密碼、驗證器遺失或通行密鑰無法使用」。

---

## 兩步驟驗證

開啟後，每次用密碼登入，都要再輸入驗證器 App（例如 Google Authenticator、1Password、iPhone 內建的密碼 App）顯示的 6 位數驗證碼。控制台要從外部連線時，建議開啟。

1. 點右上角頭像 › 帳號安全 › 兩步驟驗證。
2. 按「為這台伺服器開放兩步驟驗證」。這一步只是讓設定選項出現，還沒有開啟。
3. 按「設定兩步驟驗證」，用驗證器 App 掃畫面上的 QR code。
4. 輸入密碼與驗證器顯示的驗證碼，按「確認並開啟」。

**驗證器遺失時**，要在裝 OffiCraft 的那台 Mac 上執行指令關閉兩步驟驗證，步驟見 [常見問題與排解](troubleshooting.md) 的「忘記密碼、驗證器遺失或通行密鑰無法使用」。

想知道更多細節，例如不掃 QR code 的其他設定方式、怎麼關閉兩步驟驗證，見 [介面說明](interface.md) 的「帳號安全與登入」。

---

## 通行密鑰

通行密鑰讓你用 Face ID、Touch ID、指紋、裝置密碼或實體安全金鑰登入，不用輸入密碼，也不用輸入兩步驟驗證的驗證碼。用密碼登入的方式仍然可以用。

1. 點右上角頭像 › 帳號安全 › 通行密鑰。
2. 在「新增通行密鑰」輸入目前的密碼，以及一個認得出來的裝置名稱（例如「Eva 的 MacBook」）。
3. 按「新增通行密鑰」，照瀏覽器跳出的對話框完成。

之後登入頁會出現「用通行密鑰登入」。

**每一把通行密鑰只能在新增時用的網址使用。** 用不同網址打開控制台（例如轉發後的 HTTPS 網址和 `http://localhost:7755`）時，要在每個網址各自新增。用 `http://127.0.0.1:7755` 這類 IP 位址打開時，不能使用通行密鑰，請改用 `localhost` 網址打開，兩個網址打開的是同一間工作室。

清單上的通行密鑰出現「可能被複製，建議刪除」時，刪除那一把，再用原本的裝置重新新增。遺失其中一台裝置時，用密碼或其他裝置的通行密鑰登入，在清單上把遺失裝置的那一把刪除。

想知道更多細節，例如支援的瀏覽器版本、清單上每個標示的意思，見 [介面說明](interface.md) 的「帳號安全與登入」。

---

## 登入有效期

登入後多久需要重新登入，在 **設定 › 參數調整 › 登入有效期** 調整，可選 12 小時、24 小時、7 天、30 天，預設 24 小時。新的設定從下一次登入開始生效。

控制台會從外部連線，或會在別人也碰得到的裝置上登入時，建議選短一點。

---

## 一次性登入連結

一次性登入連結讓你不用輸入密碼和驗證碼就能登入，適合在手機上登入時使用。產生連結要在裝 OffiCraft 的那台 Mac 上，打開「終端機」執行指令。這項功能預設關閉。

1. 第一次使用前，先開啟功能：

   ```bash
   ~/.officraft/bin/ocserverd login-link enable
   ```

2. 產生一條連結。把網址換成你平常打開控制台的網址（例如轉發後的 HTTPS 網址）：

   ```bash
   ~/.officraft/bin/ocserverd login-link --base-url https://你的控制台網址
   ```

   畫面會印出一條登入連結。

3. 把連結傳到要登入的裝置（例如用 AirDrop 或傳給自己的訊息），打開就會直接登入。

**連結 10 分鐘內有效，只能用一次。** 拿到連結的人就能登入，請只在自己的裝置上打開，不要轉傳。

用完之後，建議把功能關閉，所有連結會立即失效：

```bash
~/.officraft/bin/ocserverd login-link disable
```

連結打不開時的處理，見 [常見問題與排解](troubleshooting.md) 的「一次性登入連結打不開」。

## 密鑰與 vault.key

「密鑰」分頁裡的值，是用一個叫 `vault.key` 的檔案加密後存進資料庫的。官方 release 安裝時，`vault.key` 在 `~/.officraft/server/data/vault.key`，和資料庫放在同一個資料夾。

**資料庫備份不包含 `vault.key`**，所以要另外保存：

- 把 `vault.key` 另外保存在安全、只有你能讀的地方，不要和資料庫備份放在一起。
- 從備份還原資料庫時，要把同一個 `vault.key` 放回資料庫所在的資料夾。少了 `vault.key`，原本的密鑰無法讀取，也無法修改或新增密鑰，只能在密鑰分頁把現有的密鑰刪除後重新建立。

資料庫的備份與還原步驟，見 [常見問題與排解](troubleshooting.md) 的「備份與還原」。新增、修改、刪除密鑰，以及成員怎麼取用，見 [把帳號金鑰交給成員用（密鑰）](secrets.md)。

## 簽章金鑰

簽章金鑰是 OffiCraft 用來證明登入狀態與分享連結有效的金鑰。你的登入、成員與機器的登入，以及「複製對外連結」和「複製分享連結」產生的連結，都靠簽章金鑰確認。

懷疑登入狀態或分享連結外流時：

1. 到 **設定 › 系統更新與備份** 最下方的「簽章金鑰」卡，按「產生新金鑰」。新金鑰立即接手，已登入的人不會被登出。
2. 等每一台機器都上線過一次，換成新金鑰。
3. 在舊金鑰旁按「移除」。

**移除無法復原，而且立即生效**：舊金鑰簽過的登入與分享連結全部失效，持有連結的人不會收到通知；還沒換到新金鑰的機器會立刻斷線。所以移除之前，請確認每台機器都已經上線過。

想知道更多細節，例如卡上「使用中」和「舊金鑰（仍有效）」的差別，見 [設定與參數](settings.md) 的「系統更新與備份」。成員與機器各自的登入有效期，見 [設定與參數](settings.md) 的「參數調整」。
